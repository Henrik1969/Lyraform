## Purpose and scope

C++ compiler formatting versus the inherited C++ supplement.

## Local wording, rationale and decision

The Flowcore compiler's existing `IndentWidth: 4` and `TabWidth: 4` match
Henrik's ruling: one indentation level and one tab stop are four columns.
The [C++ supplement v1.1](../../Policies/languages/CPP.md) replaces the earlier
two-space convention. This resolves the mismatch through the shared parent
policy, not a local waiver. `ContinuationIndentWidth: 8` is two four-column
units for continuation alignment, not eight-column block indentation.
The existing on-disk path `Lyraform/compiler` is retained as a locator; it is
not a new project naming decision. No source reformatting was performed.
