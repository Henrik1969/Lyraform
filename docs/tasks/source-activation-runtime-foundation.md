# Source activation runtime foundation

ID: `lyraform.source-activation-runtime`; revision 1. Owner Henrik Sørensen.
Selected on `experiment/configresolve-lyraform` by the authorized maturation
continuation. Baseline HEAD b50534c380879a5a70a77ed5c1dd442bfc4142bd plus preserved
working-tree changes through the failure-envelope identity checkpoint.

Intent: reach real source recovery execution for the ConfigResolve language
profile. Measurable prerequisite: a C runtime frame accepts source-derived
resolved identities, retains immutable failure/fault evidence, closes a selected
recovery obligation exactly once, publishes exclusively, and returns an explicit
quarantine result without process exit. It must reject wrong identity, type,
commit evidence and repeated or post-quarantine transitions without mutation.

Convergence contract: source semantic analysis remains the authority for legal
routes; the existing graph validator checks identity and selected policy. This
runtime executes prevalidated facts and must not select routes or resolve names.
ADR 0062/0063/0065/0066/0067 supply envelope immutability, evidence retention,
exclusive publication and explicit quarantine law. The C storage layout is a
private backend ABI, not ordinary-record language semantics. One serial frame,
no siblings or prior publication, caller-owned stable evidence and payload
storage retained through host consumption. No allocation, callbacks, exceptions,
TLS, unwinding or process exit in the frame implementation.

Reuse existing graph/source validation in the source-driven test driver; retain
existing C++ reference executors as independent oracles, not executable source
runtime adapters (they use exception transport). This is a runtime foundation,
not another semantic executor or a new serialized schema. The next integration
must wire generated native and TinyVM operations into these exact transitions;
no source execution claim or lowering-plan readiness change is authorized by
this prerequisite alone. Gate 4 transformation projection remains incomplete.

Tasks: inspect accepted authority and existing runtime; implement frame and
const evidence access; exercise it with real compiler-produced graph identities;
positive, negative, hostile and sanitizer checks; canonical doctor/build/test;
checkpoint and exact-mission state. Falsifiers include changed evidence after
recovery, two publications, callback/name-based policy lookup, non-success
converted by a forbidden transition, or observable continuation after quarantine.

Accepted meaning: cited ADRs. Implemented coverage before this mission: graph
version 2, no source execution. Proposed ordinary-record construction remains
awaiting owner decision and is independent. Unsupported: arbitrary graph
composition, transformation chains, response-attempt faults, evidence escape,
concurrent activations and source lowering integration. No main merge, commits,
push, FlowLFS edits or changes to the read-only ConfigResolve oracle.
